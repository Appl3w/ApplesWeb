About Apple's Web
Personal Programming & Web Development Project

Welcome to My Project

Apple's Web is an independent web development project created entirely by me to practice and demonstrate HTML, CSS, and modern front-end layouts. Inspired by clean, classic information hubs, this website combines responsive design with a custom-styled Wikipedia aesthetic.

Project Objectives

  • Responsive Grid Layouts: Utilizing CSS Grid and Flexbox to build adaptive interfaces for desktop and mobile devices.
  • Custom UI Elements: Implementing interactive components like a floating dropdown menu, dark search controls, and pixel-aligned elements.
  • Curated Knowledge Hub: Organizing diverse topics ranging from science and history to technology, mathematics, and gaming into an accessible portal.

Built With

This site was crafted using clean HTML5, CSS3 for styling and responsive breakpoints, and lightweight vanilla JavaScript for dynamic components.
